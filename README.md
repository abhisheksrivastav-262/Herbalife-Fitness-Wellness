Design Direction

Create a clean, energetic and professional fitness/wellness design. The website should feel healthy, motivating, trustworthy and premium, with a modern layout suitable for a Herbalife fitness/wellness business.

Use a fresh fitness-inspired color palette with green as the primary color, supported by white, light neutrals and subtle dark text. Add smooth animations, hover effects, rounded cards, clean typography and plenty of whitespace.

Use high-quality fitness and wellness images relevant to:

Healthy lifestyle

Fitness and exercise

Nutrition

Wellness drinks/shakes

Healthy people with active lifestyles

Weight-management/wellness motivation

Do NOT use unrelated stock images. Images should look natural, professional and premium.
